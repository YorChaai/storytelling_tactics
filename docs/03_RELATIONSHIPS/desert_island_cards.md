# Desert Island Cards

Desert Island Cards adalah 7 kartu inti yang cocok untuk mode pemula atau mode terbatas.

## Cards

1. The Dragon & The City
2. Story Listening
3. Trust Me, I'm an Expert
4. Pitch Perfect
5. Man in a Hole
6. Movie Time
7. Story Bank

## Fungsi Dalam Aplikasi

- Mode khusus berisi 7 kartu inti.
- Cocok untuk user baru.
- Cocok untuk quick play.
- Dapat menjadi preset deck.

## Gameplay

- User masuk ke mode Desert Island.
- Aplikasi hanya melakukan draw dari 7 kartu ini.
- Tidak ada duplicate dalam satu session, kecuali user melakukan reset.
