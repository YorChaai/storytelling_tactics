# Recipe Combinations

Dokumen ini akan menyimpan mapping Recipe ke tactic cards.

## Recipe Cards

- Stories that Sell
- Stories that Motivate
- Stories that Convince
- Stories that Connect
- Stories that Explain
- Stories that Lead
- Stories that Impress

## Data Yang Dibutuhkan

Untuk setiap recipe:

- goal
- recommended tactics
- suggested order
- optional cards
- example usage

## Template

```text
## Stories that ...

Goal:

Recommended tactics:
- ...

Suggested flow:
...
```
