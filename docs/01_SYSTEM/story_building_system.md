# Story Building System

Story Building System adalah navigator utama deck.

Kartu ini bukan tactic biasa. Fungsinya membantu user menentukan kategori kartu mana yang perlu dipakai berdasarkan masalah storytelling yang sedang dihadapi.

## Fungsi

Mengarahkan user dari problem storytelling menuju jenis kartu yang relevan.

## Alur Konseptual

- Jika user belum tahu kenapa membutuhkan cerita, mulai dari `Concept`.
- Jika user tahu alasan bercerita tetapi belum tahu menemukan cerita, mulai dari `Explore`.
- Jika user sudah punya cerita tetapi belum tahu siapa/peran karakter, masuk ke `Character`.
- Jika user tahu cerita tetapi belum tahu penggunaannya, masuk ke `Function`.
- Jika user butuh bentuk alur, masuk ke `Structure`.
- Jika user ingin cerita lebih menarik/diingat, masuk ke `Style`.
- Jika user ingin menyimpan, memilih, atau menyesuaikan cerita, masuk ke `Organise`.
- Jika user punya goal spesifik, gunakan `Recipe`.
