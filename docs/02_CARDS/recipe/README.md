# Recipe Cards

Recipe cards adalah mode goal-based. Setiap recipe merekomendasikan kombinasi beberapa tactic untuk menyelesaikan problem storytelling tertentu.

## Cards

- Stories that Sell
- Stories that Motivate
- Stories that Convince
- Stories that Connect
- Stories that Explain
- Stories that Lead
- Stories that Impress

## Fungsi Dalam Aplikasi

- User memilih recipe.
- Aplikasi hanya mengambil kartu dari subset tactic milik recipe tersebut.
- Recipe dapat dimainkan sebagai urutan tactic atau sebagai daftar rekomendasi.
