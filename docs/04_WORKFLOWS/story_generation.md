# Story Generation Workflow

Untuk MVP, aplikasi tidak menghasilkan cerita otomatis.

## Prinsip

Aplikasi hanya menyediakan kartu dan instruksi visual. User tetap membuat cerita secara manual berdasarkan kartu yang muncul.

## Basic Flow

1. User draw kartu.
2. User membaca kartu.
3. User menerapkan tactic secara manual.
4. User draw kartu berikutnya jika dibutuhkan.
5. User menyelesaikan cerita di luar aplikasi atau di notes sederhana.

## Future Option

Jika nanti ingin menambahkan AI assistant, flow ini dapat diperluas menjadi:

- user goal capture
- card recommendation
- story draft generation
- explain which card influenced which story part

Untuk sekarang, fitur AI gameplay bukan bagian dari MVP.
