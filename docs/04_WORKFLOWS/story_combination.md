# Story Combination Workflow

Story combination adalah cara user memakai beberapa kartu sekaligus.

## 3-Card Challenge

1. Draw kartu pertama.
2. Draw kartu kedua.
3. Draw kartu ketiga.
4. User memakai ketiganya untuk membuat satu cerita.

## Three Stories Mode

1. Aplikasi membuat 3 set kartu.
2. Setiap set menjadi kandidat cerita.
3. User membandingkan hasil.
4. User memilih cerita favorit.

## Example Layout

```text
Story 1: Hero & Guide + Movie Time + Downfall
Story 2: Order & Chaos + Story Hooks + Rags to Riches
Story 3: Social Proof + Man in a Hole + Show & Tell
```

## Rule

Untuk MVP, aplikasi tidak menilai cerita. User sendiri yang memilih hasil terbaik.
