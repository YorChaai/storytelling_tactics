# Recommendation Rules

Dokumen ini disiapkan untuk fase setelah MVP.

Pada MVP, recommendation rules belum wajib karena aplikasi bekerja sebagai card engine.

## Future Rules

```text
IF user_goal = "start presentation"
THEN recommend:
- Story Hooks
- Secrets & Puzzles
- Curious Tales
```

```text
IF user_goal = "sell product"
THEN recommend:
- Hero & Guide
- Simple Sales Stories
- Social Proof
- Rags to Riches
```

```text
IF user_goal = "explain complex idea"
THEN recommend:
- Movie Time
- Show & Tell
- Abstractions
```

## Status

Disimpan sebagai future feature. Jangan dijadikan scope MVP sampai rules dan metadata kartu lengkap.
