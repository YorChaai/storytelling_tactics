# AI Behavior

Dokumen ini membatasi peran AI dalam proyek.

## Current Role

AI digunakan sebagai development collaborator:

- membantu ide
- menyusun PRD
- memecah implementation plan
- membuat task
- membantu coding hanya jika diminta

## Gameplay Role

Untuk MVP, AI tidak menjadi pemain, coach, atau story generator di aplikasi.

## If AI Assistant Is Added Later

Jika nanti fitur AI dimasukkan ke produk, AI harus:

1. Memahami goal storytelling user.
2. Mengidentifikasi problem.
3. Merekomendasikan kartu relevan.
4. Menjelaskan alasan pilihan kartu.
5. Menggabungkan kartu bila berguna.
6. Menunjukkan kartu mana yang memengaruhi bagian cerita.
7. Mengizinkan user mengganti kartu.

## Current Constraint

Jangan desain MVP dengan ketergantungan ke LLM.
