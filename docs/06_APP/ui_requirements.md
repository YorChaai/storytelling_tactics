# UI Requirements

## Screens

- Home
- Card Catalog
- Random Draw
- Three Stories
- Recipe
- Desert Island
- Session History
- Card Detail

## Home

Menampilkan mode utama:

- Pick Any Card
- Three Stories
- Recipe
- Desert Island

## Card Detail

Menampilkan:

- nama kartu
- kategori
- gambar kartu
- status desert island jika ada

## Random Draw

User bisa:

- memilih jumlah kartu
- draw
- melihat hasil
- draw again
- reset session

## Three Stories

Menampilkan 3 kelompok kartu agar user bisa membandingkan tiga kemungkinan cerita.

## Recipe

Menampilkan daftar recipe dan tactic yang terkait.

## Desert Island

Menampilkan 7 kartu inti sebagai deck khusus.
