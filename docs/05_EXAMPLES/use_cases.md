# Use Cases

## Beginner

User baru ingin belajar storytelling tanpa membaca semua kartu.

Recommended mode:

- Desert Island
- Random 1 Card

## Workshop

Facilitator ingin peserta membuat beberapa variasi cerita.

Recommended mode:

- Three Stories
- 3-Card Challenge

## Presentation Prep

User ingin menyiapkan presentasi dengan struktur cerita.

Recommended mode:

- Recipe
- Random 3 Cards

## Exploration

User ingin menemukan sudut pandang baru dari ide yang sudah ada.

Recommended mode:

- Pick Any Card
- Concept-only deck
- Explore-only deck
